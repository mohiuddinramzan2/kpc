# কাউন্টার হিসাব — সার্কুলার নিটিং প্রোডাকশন ক্যালকুলেটর

সার্কুলার নিটিং মেশিনের প্রোডাকশন (কাউন্টার), নিডেল সংখ্যা ও ফিটার সংখ্যা হিসাব করার জন্য একটি সিম্পল, ফাস্ট, মোবাইল-ফ্রেন্ডলি ওয়েব অ্যাপ। কোনো ব্যাকএন্ড/বিল্ড স্টেপ নেই — শুধু HTML, CSS আর ভ্যানিলা JavaScript, তাই GitHub Pages-এ সরাসরি চলে।

## ব্যবহৃত সূত্র

**নিডেল সংখ্যা**
```
নিডেল = ডায়া × গেজ × ৩.১৪
```

**ফিটার সংখ্যা**
```
স্ট্যান্ডার্ড মেশিন : ফিটার = ডায়া × ৩
Mayer & Cie মেশিন   : ফিটার = ডায়া × ৩ + ৬
কার্যকর ফিটার        = মোট ফিটার − মিস ফিটার
```

**কাউন্টার (কেজি থেকে)**
```
কাউন্টার = কেজি × ১৬,৯৩৬,৫১৭ × ইয়ার্ন কাউন্ট ÷ এস.এল ÷ নিডেল ÷ কার্যকর ফিটার
```

**উৎপাদন (কাউন্টার থেকে, বিপরীত হিসাব)**
```
কেজি = কাউন্টার × এস.এল × নিডেল × কার্যকর ফিটার ÷ (১৬,৯৩৬,৫১৭ × ইয়ার্ন কাউন্ট)
```

অ্যাপে ঐচ্ছিকভাবে মেশিনের RPM দিলে আনুমানিক সময়ও (ঘণ্টা/মিনিট) দেখায়।

## ফাইল স্ট্রাকচার

```
.
├── index.html                     # মূল পেজ
├── style.css                      # ডিজাইন (ইন্ডাস্ট্রিয়াল কন্ট্রোল-প্যানেল থিম)
├── app.js                         # হিসাবের লজিক
└── .github/workflows/deploy.yml   # GitHub Pages-এ অটো-ডিপ্লয়
```

## GitHub-এ বসিয়ে লাইভ করবেন যেভাবে

1. GitHub-এ একটা নতুন repository তৈরি করুন (public হলে সবচেয়ে সহজ, নাম যেকোনো — যেমন `knitting-counter`)।
2. এই ফোল্ডারের সব ফাইল (`index.html`, `style.css`, `app.js`, `.github` ফোল্ডারসহ) repository-তে আপলোড/পুশ করুন এবং `main` ব্র্যাঞ্চে কমিট করুন।
   ```bash
   git init
   git add .
   git commit -m "Initial commit: counter calculator"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. GitHub repository-তে যান → **Settings → Pages** → "Build and deployment" এর **Source** অপশনে **GitHub Actions** সিলেক্ট করুন।
4. `main`-এ পুশ করার সাথে সাথে `.github/workflows/deploy.yml` অ্যাকশনটা নিজে থেকেই রান হয়ে অ্যাপ ডিপ্লয় করবে। কয়েক মিনিট পর **Settings → Pages**-এ URL পাবেন, সাধারণত:
   ```
   https://<your-username>.github.io/<repo-name>/
   ```
5. এরপর থেকে যেকোনো পরিবর্তন `main`-এ পুশ করলেই সাইট অটো-আপডেট হবে।

## লোকালি টেস্ট করা

আলাদা কোনো সার্ভার/বিল্ড টুল লাগবে না — শুধু `index.html` ব্রাউজারে খুললেই চলবে। চাইলে সিম্পল লোকাল সার্ভার দিয়েও দেখতে পারেন:

```bash
python3 -m http.server 8000
# তারপর ব্রাউজারে http://localhost:8000
```

## কাস্টমাইজেশন

- মিস ফিটার / মেশিন টাইপ / ধ্রুবক (১৬,৯৩৬,৫১৭) — সবকিছু `app.js`-এর ওপরের দিকে পরিষ্কারভাবে লেখা আছে, প্রয়োজনে সহজেই বদলানো যাবে।
- রং, ফন্ট বদলাতে চাইলে `style.css`-এর একদম উপরে `:root` অংশের ভ্যারিয়েবলগুলো বদলান।
